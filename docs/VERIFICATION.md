## 历史真实谱面性能（adapter-2）

2026-11-14，从本地 7K 数据集按大小分层抽取 48 张，Detailed / NM，仅复制到临时目录，不发布谱面。
单线程、4 线程、暖缓存的完整结果相等，48 张均评分与分类成功。

| 路径 | 用时 |
|---|---:|
| 首次、1 worker | 8,899 ms |
| 首次、4 workers | 4,419 ms |
| 持久缓存、无引擎调用 | 约 5 ms |

此次首次分析并行加速 2.01×；计时包含发现文件、缓存检查、分析、日志与快照，不包含启动和绘制。
这是历史单机测量，未用来宣称本次算法更快。本次性能修复重点是保留有效结果，不因应用界面更新重跑。
