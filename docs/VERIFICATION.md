# SPM Box 0.1.0 验证记录

2026-11-14，Windows x64，Node 24.22.1，AMD Ryzen 5 5600（12 个逻辑处理器）。

## 算法结果与安全行为

`npm test`：13 个测试通过，覆盖：

- 36 个组合（4K/6K/7K × RC/LN × Detailed/Compact × HT/NM/DT）。
  优化后的批量适配器与固定上游 `processMap` 的总分、RC/LN 和完整默认标签完全相等；
  7K classifier 确认消耗同一次评分的原始难度输入。
- 阈值含等号、边界排序、谱面 ID、仅 7K、MD5 去重和参数校验。
- 首次与持久缓存命中、同路径改动、删图、模型/速率变体、取消保留完整库、损坏日志恢复。
- 独立二进制样本、Unicode/长字符串、损坏数据库拒写。
- 用户同显示名收藏夹保留，自动收藏夹可重复更新，手动改动/重复标识拒绝接管。
- 外部修改使预览失效、锁与中断记录拒写、仅删除有证据的自动收藏夹、数据库与标识配对恢复。
- 标识文件替换失败时回滚数据库，仍保留配对备份；默认预设逐项保留原始标签，纯 RC 不会被数值 Hybrid 误选。

`npm run test:ui`：在真实 Electron 窗口通过扫描、排序、搜索、详情、19 分类预设、数值阈值、
边界 ID、写入确认、用户收藏夹保护、1050 px 窗口与旧分析阻止写入检查。无 renderer 异常。
源码版与打包后的 `app.asar` 均通过同一套交互检查（包括后台 worker 的打包内加载）。
截图来自生成的测试谱面，已人工检查实际渲染。所有写入仅发生在临时数据库。

## 真实谱面性能

从本地 7K 数据集按文件大小分层选取 48 张，Detailed / NM。只复制到临时目录，未发布谱面。
单线程、4 线程及缓存运行的完整有效结果均相等；48 张均分析和分类成功。

| 路径 | 用时 |
|---|---:|
| 首次、1 worker | 8,899 ms |
| 首次、4 workers | 4,419 ms |
| 持久缓存、无引擎调用 | 约 5 ms |

本次首次分析并行加速 **2.01×**。这是一次本机运行，不是跨机器性能保证。
计时包含发现文件、校验缓存、分析、日志与库快照持久化，不包含 UI 绘制和首次应用启动。
冷缓存与暖缓存经过相同的文件属性检查；缓存命中不再读取和分析谱面正文。
