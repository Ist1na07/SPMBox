ONLY WHAT BELONGS TO SPM BOX

收藏夹管理.

你的收藏夹，始终由你掌控。

只有名称标识、管理记录和谱面列表均匹配的收藏夹才能被更新或删除。手动修改过的收藏夹会被保护。

恢复收藏夹

恢复整个 collection.db 及其管理标识；之后新增的手动收藏夹也会被回退。恢复前仍会备份当前文件。

BUILT AROUND SPM

设置与关于.

保持算法原貌，把时间花在打谱上。

谱面分析

修改算法或速率后，回到谱面库重新分析。
已缓存的其他组合仍然保留。

缓存与数据

文件大小、修改时间和变更时间不变的谱面直接复用结果。
新建或改动的谱面才会交给后台分析。

缓存按算法版本、模型、速率及绝对路径隔离。
收藏夹备份保存在 osu! 目录下的 .spmbox-backups。
